# TypeFast frontend

React + Vite single-page app. See the [root README](../README.md) for what TypeFast does and how to run it.

```bash
npm install
npm run dev
```

By default the app talks to the backend at `http://localhost:5001`. To point it elsewhere, set `VITE_API_URL` at build/dev time:

```bash
VITE_API_URL=https://your-backend.example.com npm run dev
```
